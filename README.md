💰 Expense Tracker

A simple and responsive Expense Tracker web application built using HTML, CSS, and JavaScript.
It allows users to keep track of their expenses through a clean and easy-to-use interface.

🚀 Live Demo

https://jahanvi1405.github.io/Expense_Tracker/
📌 Features
➕ Add and manage expenses
💰 Track spending easily
📊 View expense information at a glance
🖥️ Clean and responsive user interface
⚡ Built with vanilla JavaScript — no frameworks required
🛠️ Technologies Used
HTML5 — Structure and content
CSS3 — Styling and responsive design
JavaScript — Application logic and interactivity
